# Install Nexis CRO on Shopify

## Install URL

https://apps.shopify.com/partners/nexis-cro

## Steps for merchants

1. Open the install URL above (or click **Install Free on Shopify** on https://nexiscro.com/)
2. Choose the target Shopify store in the Partner/App Store flow
3. Approve requested Admin API scopes
4. Open the app from Shopify Admin → Apps

## Authentication

Merchant sessions use Shopify OAuth after install. This skill covers public install
discovery only; admin API access requires an installed shop session.
